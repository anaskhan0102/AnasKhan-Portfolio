## 📖 About

This is my **personal portfolio website**, designed to highlight my professional background, showcase my best projects, and provide visitors with an easy way to connect with me.  
The website emphasizes **minimalist design**, **smooth animations**, and **fast performance**, reflecting my style as a developer.

🌟 **Live Demo:** [anaskhan-portfolio.vercel.app](https://anaskhan-portfolio.vercel.app)

---

## ✨ Features

- ✅ **Fully responsive** — optimized for all devices  
- 🌗 **Dark & light mode** toggle  
- ⚡ **Fast & lightweight** — powered by Vite  
- 🧩 **Modular architecture** with reusable React components  
- 🎨 **Beautiful UI** built using Tailwind CSS  
- 🔍 **SEO optimized** meta tags and structure  
- 💼 **Projects, skills, and contact** sections  
- 🎥 **Smooth animations and transitions**
